Projects

1.crop recommendation system

The Crop Recommendation System is a machine learning-based project that recommends the most suitable crop based on soil and weather conditions. It uses parameters such as Nitrogen, Phosphorus, Potassium (NPK), temperature, humidity, pH, and rainfall to predict the best crop for cultivation. The system uses Python, Scikit-learn, Pandas, FastAPI, and React to help farmers make better farming decisions and improve crop productivity.

2.digital health care and pharmacy integration system

The Digital Healthcare and Pharmacy Integration System is a web-based application that connects patients, diagnostic laboratories, and pharmacies on a single platform. It enables patients to access digital lab reports and prescriptions, while pharmacies can manage medication-related information. The system uses React.js for the frontend, FastAPI for the backend, and MongoDB for database management. It also provides abnormal lab value alerts and drug interaction alerts to improve patient safety and healthcare efficiency.
